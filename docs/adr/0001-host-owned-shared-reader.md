# ADR 0001: 宿主统一阅读器与来源适配器

## 状态

已接受。

## 背景

本地漫画和漫画源内容需要共享阅读交互、OCR、导航以及收藏、书签、进度和历史。若插件提供阅读器或在线漫画伪装成本地 `ComicEntity`，宿主行为会分叉，来源身份也会与 Room 行 ID 或临时 URL 错误绑定。

## 决策

- Inkleaf 宿主拥有统一阅读器 UI、OCR、章节/页面导航和全部用户记录。
- 本地文件与漫画源分别提供来源适配器，只负责解析或获取内容。
- 本地内容以稳定文件键标识；在线内容以插件 ID 和来源 ID 标识，并逐层增加章节 ID 与页面 ID。
- 来源无稳定页面 ID 时，页面身份退化为章节 revision 和页索引的组合。
- 在线内容不创建合成 `ComicEntity`。插件不可用只改变可用性，不删除用户记录或最近可靠快照。

## 后果

阅读器功能只需在宿主实现一次，但来源适配器必须保留请求头、referer 和 revision 等读取上下文。页面收藏的图片属于宿主的应用私有用户数据；页面书签只保存轻量位置。
