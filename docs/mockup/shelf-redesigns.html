#shelf-ambient方案 A · 氛围沉浸

书架即"正在读的那本书"：顶部 Hero 区用当前封面的取色弥散做背景，一键续读；下面才是收藏。没有 TopAppBar，全屏 edge-to-edge。

  • Palette 取色：androidx.palette 从封面提主色 → Hero 渐变背景（DB 加 coverColor 列，生成封面时顺手算）
  • M3 Carousel：material3 1.3+ 的 HorizontalMultiBrowseCarousel，大-中-小 peek 布局
  • edge-to-edge：内容绘到状态栏后面（Android 15 起强制），WindowInsets 只给文字让位
  • 动效预留：封面 → 阅读页可做 SharedTransition（Compose 1.7+ SharedTransitionLayout）
  • 取舍：信息密度低、强依赖"有封面"；搜索/管理入口收进右上角菜单

#shelf-hub方案 B · 检索工作台

书多了以后的形态：搜索 + 状态过滤 + 瀑布流（封面原始比例不裁剪，信息叠在卡内）。顶栏图标堆改为底部导航三页签，刷新改下拉手势。

  • SearchBar：material3 自带组件，点开变全屏搜索态（Room 加 LIKE 查询即可）
  • FilterChip：在读/未读/失效 过滤——数据全在 ComicEntity 里，纯查询变化
  • LazyVerticalStaggeredGrid：foundation 自带瀑布流；需 DB 存封面宽高比（生成封面时已知）
  • PullToRefreshBox：material3 1.3+ 下拉刷新，替代顶栏 Refresh 按钮
  • NavigationBar：底导替代"图标都挤在顶栏"，库目录/设置升级为一级页面
  • 取舍：底导占掉 80dp 高度；瀑布流两列下单屏可见本数少于三列网格
两案可混搭：例如 方案 B 的骨架（搜索/过滤/底导）+ 方案 A 的"继续阅读" Hero 压缩成列表顶部一张横幅卡。 共享组件样式来自 mockup.css，本页特有样式（氛围背景 / Carousel / 瀑布流 / 底导）写在页内 <style>，定稿后再下沉到共享库。
