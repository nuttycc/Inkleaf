# 阅读活动历史：低保真时间线原型

状态：已确认，用于 [验证历史时间线的信息架构与会话项交互](https://github.com/nuttycc/Inkleaf/issues/13) 的 HITL 评审。

## 已确定约束

- “历史”是独立顶层目的地。
- 页面按阅读会话时间倒序，并按日期分组。
- 首要任务是回顾阅读活动，并从某次会话的结束位置继续阅读。
- 本原型只描述交互与信息层级，不决定 Room schema 或会话计时规则。

## 第一轮：正常时间线

```text
┌────────────────────────────────────┐
│ 历史                            ...│
│                                    │
│ 今天                               │
│ ┌──────┐ 葬送的芙莉莲          ...│
│ │ 封面 │ 第 3 章 · 第 68 页        │
│ │      │ 21:18-21:46 · 阅读 28 分钟│
│ └──────┘                           │
│          ───────────────────────── │
│ ┌──────┐ 地。                  ...│
│ │ 封面 │ 第 12 章 · 第 21 页       │
│ │      │ 15:03-15:11 · 阅读 8 分钟 │
│ └──────┘                           │
│                                    │
│ 昨天                               │
│ ┌──────┐ 葬送的芙莉莲          ...│
│ │ 封面 │ 第 2 章 · 第 44 页        │
│ │      │ 23:07-23:32 · 阅读 25 分钟│
│ └──────┘                           │
│                                    │
├────────────────────────────────────┤
│  书架       历史      已保存    现有预留│
└────────────────────────────────────┘
```

## 推荐的信息层级

1. 漫画标题是主信息，最多两行，超过后省略。
2. 第二行只显示会话结束位置，因为整行点击的主要结果是从这里继续阅读；起始位置保留在数据中，但不占用常规列表空间。
3. 第三行显示开始时间、结束时间和有效阅读时长，支持快速回顾且不引入统计卡片。
4. 左侧使用 `56dp`、`2:3` 的漫画封面或稳定回退图，与现有“已保存”列表保持一致。
5. 整行点击即从结束位置继续阅读；行尾菜单承载单条删除等次要动作。
6. 日期标题使用轻量表面色分组；列表保持无卡片、细分隔线的平面结构。

评审结果：已接受。

## 第二轮：删除入口

- 单条记录：行尾菜单提供“删除记录”。执行后立即从列表移除，并显示带“撤销”动作的 Snackbar，不弹确认对话框。
- 清空全部：页面顶栏菜单提供“清空历史”。点击后显示确认对话框，明确说明只删除阅读活动历史，不影响书架、阅读进度、书签或收藏。
- 清空确认文案：标题“清空阅读历史？”；正文“所有阅读会话记录都将被删除。书架、阅读进度和已保存内容不会受到影响。”；操作“取消 / 清空”。
- 清空完成后进入空状态，不再提供第二次撤销入口；确认对话框承担防误触责任。

评审结果：已接受。

## 第三轮：空历史

```text
┌────────────────────────────────────┐
│ 历史                            ...│
│                                    │
│                 ◷                  │
│          还没有阅读历史             │
│   打开书架中的漫画开始阅读，         │
│   阅读记录会显示在这里。             │
│                                    │
├────────────────────────────────────┤
│  书架       历史      已保存    现有预留│
└────────────────────────────────────┘
```

- 使用 Material 历史图标、`titleLarge` 标题和 `bodyLarge` 说明，沿用现有居中空状态语言。
- 不增加“前往书架”按钮；底部导航中的“书架”已是持续可见且更稳定的入口，避免重复主操作。
- 空状态不展示清空菜单项。

评审结果：已接受。

## 第四轮：内容不可用

```text
│ ┌──────┐ 迷宫饭              ...│
│ │ 封面 │ 第 7 章 · 第 35 页      │
│ │ 55%  │ 20:16-20:41 · 阅读 25 分钟│
│ └──────┘ 内容不可用               │
```

- 保留漫画标题、会话结束位置和时间信息，封面或回退图降至 `55%` 透明度。
- 使用简短的“内容不可用”状态文本，并使用 Material `error` 角色确保状态可识别。
- 会话行不响应继续阅读，也不显示进入箭头；无效操作不产生涟漪或页面跳转。
- 行尾菜单仍可用，但只提供“删除记录”。
- 无障碍语义把整项描述为不可用，不能只依赖透明度或颜色。

评审结果：已接受。

## 第五轮：底部导航顺序

- “历史”使用当前第二个未启用的底部栏位置，排列为“书架 / 历史 / 已保存 / 现有预留”。
- 该位置让自动产生的阅读轨迹紧邻主要阅读入口，同时保持“已保存”的既有位置不变。
- 本票据不改变第四个预留位置，也不把现有设置页面提升为顶层目的地。

评审结果：已接受。

## 第六轮：加载状态

- 首次等待本地历史数据时，保留顶栏和底部导航，列表区域显示三条与真实会话项同高的静态骨架占位。
- 骨架使用 Material 表面色角色，不使用居中进度圈、闪烁 shimmer 或循环装饰动画。
- 数据到达后原位替换骨架，避免页面高度突变；已加载过的顶层页面恢复时直接显示保留的列表状态。
- 加载状态不显示日期标题、清空菜单或误导性的空状态文案。

评审结果：已接受。

## 第七轮：窄屏与大字体

- 会话项高度由内容决定，不固定行高；封面保持 `56dp`、`2:3` 并与文本顶部对齐。
- 漫画标题最多两行，超过后省略；结束位置、时间范围、阅读时长和“内容不可用”状态允许自然换行，不缩小字体。
- 时间范围与阅读时长在空间不足时拆成两行，不能为了单行展示而隐藏有效阅读时长。
- 行尾菜单保持至少 `48dp` 触控区域；正文变高时仍顶部对齐，避免漂到行中央。
- 支持至少 `320dp` 紧凑宽度和 Android `200%` 系统字体缩放，不出现横向滚动、文字遮挡或操作重叠。
- 日期标题、空状态和确认对话框均使用 Material typography 角色随系统字体缩放。

评审结果：已接受。
